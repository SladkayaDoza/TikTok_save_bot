# TikTok Save Bot

Телеграм-бот для группового чата: ловит ссылки на TikTok, YouTube и Instagram,
скачивает медиа и выкладывает его прямо в чат. Видео остаётся в Telegram навсегда,
даже если оригинал удалят или автор закроет профиль.

## Возможности

- **Автозагрузка** — TikTok (видео и фото-слайдшоу), YouTube (включая Shorts), Instagram (Reels и посты)
- **Дедупликация** — повторную ссылку бот узнаёт и подписывает, кто кинул её первым
- **Статистика** — `/stats`: кто сколько закинул и сколько собрал реакций
- **Транскрипция** — `meow` в ответ на любое голосовое или видео
- **Семантический поиск** — `/find` находит ролик по смыслу, а не по названию

## Требования

| | |
|---|---|
| Python | 3.10+ (нужен синтаксис `str \| None`) |
| ffmpeg | обязательно, вместе с `ffprobe` |
| Node.js, Deno или Bun | только для YouTube — решает JS-челлендж |
| Диск | ~1 ГБ на зависимости + место под очередь эмбеддингов |
| RAM | 1 ГБ достаточно; с `faster-whisper` — 2 ГБ |

## Установка

```bash
git clone https://github.com/SladkayaDoza/TikTok_save_bot.git
```

Виртуальное окружение — чтобы зависимости бота не смешивались с глобальным pip:

```bash
python -m venv .venv
```

Активация (Linux/macOS):

```bash
source .venv/bin/activate
```

Активация (Windows PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
```

Зависимости:

```bash
pip install -r requirements.txt
```

Системный ffmpeg (Debian/Ubuntu):

```bash
sudo apt install ffmpeg
```

Для YouTube нужен JS-рантайм. Если Node, Deno или Bun в системе нет, самый простой путь — поставить deno прямо через pip:

```bash
pip install "yt-dlp[deno]"
```

### Альтернатива: uv

[uv](https://docs.astral.sh/uv/) заменяет `venv` + `pip` и ставит пакеты
в 10–100 раз быстрее. Главное для этого проекта — он держит **один глобальный кеш**
и вкладывает пакеты в окружения хардлинками: один и тот же `numpy` или `torch`
физически лежит на диске в единственном экземпляре, сколько бы проектов его ни
использовали.

```bash
uv venv && uv pip install -r requirements.txt
```

Запуск без ручной активации окружения:

```bash
uv run python main.py
```

## Настройка

```bash
cp .env.example .env
```

Обязательных полей всего два:

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_ADMIN_ID` | [@userinfobot](https://t.me/userinfobot) — только этот аккаунт управляет ботом |

Всё остальное включает дополнительные функции. **Без единого API-ключа бот
запускается и качает видео как обычно** — просто `/find` и `meow` сообщат,
что не настроены.

| Ключ | Что включает |
|---|---|
| `OPENROUTER_API_KEY` | семантический поиск **и** распознавание речи — одного ключа достаточно |
| `DEEPINFRA_API_KEY` | только распознавание речи, если не хочешь заводить OpenRouter |

Для Instagram может понадобиться `cookies.txt` в корне проекта — экспорт кук
залогиненного аккаунта в формате Netscape.

## Запуск

```bash
python main.py
```

Дальше добавь бота в группу, дай права на отправку сообщений и выполни `/setup`.

### Автозапуск на сервере (systemd)

Создай `/etc/systemd/system/tiktok-bot.service`:

```ini
[Unit]
Description=TikTok Save Bot
After=network-online.target

[Service]
Type=simple
User=YOUR_USER
WorkingDirectory=/path/to/TikTok_save_bot
ExecStart=/path/to/TikTok_save_bot/.venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now tiktok-bot
```

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/setup` | админ | включить автозагрузку в этом чате |
| `/disable` | админ | выключить автозагрузку |
| `/stats` | все | таблица: видео и реакции по участникам |
| `meow` | все | реплаем на медиа — распознать речь |
| `/embed_on` | админ | включить семантический поиск в этом чате |
| `/embed_off` | админ | выключить индексацию (индекс сохраняется) |
| `/find текст` | все | найти видео по смыслу, топ-5 со ссылками |
| `/similar` | все | реплаем на видео — найти похожие |
| `/embed_status` | все | что проиндексировано, очередь, остаток лимита |
| `/embed_retry` | админ | вернуть упавшие задачи в очередь |

## Распознавание речи

Используется командой `meow` и обогащением видео для поиска. Провайдер
выбирается переменной `TRANSCRIBE_PROVIDER`:

| Значение | Поведение |
|---|---|
| `auto` (по умолчанию) | DeepInfra, если есть её ключ, иначе OpenRouter, иначе выключено |
| `openrouter` | только OpenRouter — удобно, если хочется один ключ на всё |
| `deepinfra` | только DeepInfra |
| `off` | распознавание выключено полностью |

Порядок в `auto` выбран так, чтобы обновление ничего не меняло само собой:
у кого настроена DeepInfra, продолжит работать на ней.

Если провайдер недоступен, бот не падает и не молчит — `meow` отвечает, что
функция не настроена, и подсказывает, какой ключ добавить. Поиск в этом случае
продолжает работать по описанию кадров.

## Семантический поиск

Выключен по умолчанию. Нужен `OPENROUTER_API_KEY` в `.env`
([openrouter.ai/keys](https://openrouter.ai/keys)) и `/embed_on` в каждой группе отдельно.

### Как устроено

```
видео отправлено в чат
        │
        ▼  файл переезжает в embed_queue/, задача пишется в БД
   фоновый воркер
        │
        ├─ ffmpeg → аудио 16 kHz → VAD: есть ли речь?
        │     ├─ есть  → Whisper → транскрипт
        │     └─ нет   → 4 кадра → VLM → описание происходящего
        │
        └─ текст → эмбеддинг → вектор в БД и в память
```

Отправка видео в чат **не задерживается**: обогащение начинается только после того,
как ролик уже улетел в чат. Очередь живёт в базе, поэтому рестарт бота её не теряет.

Эмбеддится **текст**, а не файл. Транскрипт и описание — долговечный актив: сменишь
модель эмбеддингов, и переиндексация обойдётся в копейки. Вектор — это просто кэш.

### Сколько стоит

Примерно **$2–3 в месяц** при 500 роликах и настройках по умолчанию.
Главный рычаг — `VLM_POLICY`: `never` дешевле примерно вдвое, `always` дороже вдвое.

Встроен месячный лимит (`EMBED_MONTHLY_LIMIT_USD`, по умолчанию $5). При исчерпании
обогащение встаёт, админу приходит уведомление, а видео продолжают качаться
и отправляться как обычно. Очередь дожидается следующего месяца.

Старые видео не индексируются — только те, что пришли после `/embed_on`.

## Обновление

```bash
git pull && pip install -r requirements.txt
```

База не пострадает: `video_stats.db` в `.gitignore` и остаётся локальной, а миграция
только добавляет таблицы и индексы, ничего не переписывая. Перед первой миграцией
автоматически создаётся резервная копия `video_stats.db.bak-<дата>`.

Если `numpy` или `OPENROUTER_API_KEY` не окажется на месте, бот всё равно запустится —
просто без поиска, а причина будет видна в `/embed_status`.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | обработчики Telegram, скачивание, отправка |
| `database.py` | схема SQLite, миграции, запросы |
| `embedding.py` | очередь, описание кадров, эмбеддинги, поисковый индекс |
| `transcription.py` | распознавание речи и выбор провайдера |
| `sandbox/` | полигон для экспериментов с эмбеддингами, вне репозитория |

Локальные файлы, которых нет в git: `.env`, `video_stats.db`,
`active_groups.json`, `cookies.txt`, `embed_queue/`.
